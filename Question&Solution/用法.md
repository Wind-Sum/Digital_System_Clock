# 多功能电子表用法

## 方向约定与上板前准备

本文所有“向上/向下”都以**数码管正放、板上文字可以正常阅读**时看到的方向为准。在这个方向下，SW1～SW4 **向上是逻辑 0，向下是逻辑 1**。

- 将 **SW6 拨下**，把复用引脚连接到数码管。
- 建议先将 **SW1、SW2、SW3、SW4 全部拨上**。
- 烧写 `Vivado_Project_File/clock/batch_build/clock_top.bit`。

> SW6 是数码管/双色 LED 的硬件选择开关，不是程序中的功能输入。建议断电后再切换。

## 开关表

| 开关 | 物理向上 | 物理向下 | 说明 |
| --- | --- | --- | --- |
| SW1 | 关闭闹钟，并立即停止当前闹铃 | 开启三组闹钟 | 只控制闹钟，不影响倒计时 |
| SW2 | 暂停倒计时 | 启动或继续倒计时 | 倒计时到 `00:00` 后 LED 闪烁约 5 秒 |
| SW3 | 查看模式 | 修改模式 | 修改模式下当前字段闪烁；时间页编辑时暂停时钟 |
| SW4 | KEY4 用于解除正在响铃的闹钟 | KEY4 用于全局复位 | SW4 本身不会产生动作，必须配合 KEY4 |
| SW6 | 连接八组双色 LED | 连接八位数码管 | 正常使用电子表时应向下 |

## 按键表

| 按键 | 查看模式 | 修改模式 | 特殊说明 |
| --- | --- | --- | --- |
| KEY1 | 切换页面：时间→日期→闹钟→倒计时→时间 | 切换当前页面的修改字段 | 修改完成不需要按确认键 |
| KEY2 | 闹钟页选择上一组；其他页面无作用 | 当前字段 `+1` | - |
| KEY3 | 闹钟页选择下一组；其他页面无作用 | 当前字段 `-1` | - |
| KEY4 | 由 SW4 决定 | 由 SW4 决定 | SW4 向上：解除正在响铃的闹钟；SW4 向下：全局复位；不解除倒计时结束提醒 |

修改完成后直接将 **SW3 拨上**即可退出并保留修改结果，不需要按确认键。下次把 SW3 拨下进入修改模式时，会重新从该页面的第一个字段开始。

## 页面显示和可修改字段

下划线表示空白数码位，硬件不显示冒号。

| 页面 | 八位显示格式 | 修改字段顺序 |
| --- | --- | --- |
| 时间 | `__HHMMSS` | 小时→分钟→秒 |
| 日期 | `20YYMMDD` | 年→月→日 |
| 闹钟 | `_nHHMM__` | 小时→分钟；`n` 是第 1～3 组闹钟 |
| 倒计时 | `____MMSS` | 分钟→秒 |

字段加减只在本字段范围内循环，不会自动向相邻字段进位或借位。例如分钟 `59 + 1` 变为 `00`，小时不会跟着增加。

## 常用操作

### 设置时间、日期、闹钟或倒计时

- 保持 SW3 向上，用 KEY1 切换到需要的页面。
- 将 SW3 拨下，进入修改模式；当前字段开始闪烁。
- 用 KEY2 加一、KEY3 减一。
- 用 KEY1 切换到下一个字段，继续调整。
- 将 SW3 拨上，退出修改。

设置倒计时时，建议先将 SW2 拨上暂停，设置完成后再拨下启动。

### 使用闹钟

- 在闹钟查看页用 KEY2/KEY3 选择三组闹钟。
- 进入修改模式设置所选闹钟的小时和分钟。
- 将 SW1 拨下启用闹钟。
- 闹钟响铃时，保持 SW4 向上并按 KEY4 可立即解除。

### 全局复位

将 SW4 拨下并按下 KEY4。复位后建议把 SW4 再拨上，避免误触 KEY4 再次复位。

也可以同时按下 KEY1～KEY4 作为备用复位方式。

复位默认值：

| 项目 | 默认值 |
| --- | --- |
| 时间 | `00:00:00` |
| 日期 | `2026-01-01` |
| 闹钟 1 | `07:00` |
| 闹钟 2 | `12:00` |
| 闹钟 3 | `18:00` |
| 倒计时 | `01:00` |

## 最简正常运行配置

| 开关 | 位置 |
| --- | --- |
| SW1 | 根据是否需要闹钟选择 |
| SW2 | 根据是否需要运行倒计时选择 |
| SW3 | 上（查看模式，时钟正常走时） |
| SW4 | 上（KEY4 用于解除闹铃） |
| SW6 | 下（连接数码管） |
